cron-job.org 配置参考（已弃用存档）

任务：每 30 分钟触发 GitHub Actions 跑 A股盘中盯盘（取代不可靠的 GitHub 原生定时）
✅ 已实测：POST dispatches 返回 204，GitHub 立即出现新的 workflow_dispatch 运行并正常推送微信。下方参数为验证过的真实值。
创建 Cronjob 时逐项填写
Title选填，例如 A股盘中盯盘 scout
URLhttps://api.github.com/repos/leonmai/pushme/actions/workflows/scout.yml/dispatches
Request methodPOST
Request body typeapplication/json
Request body / POST data{"ref":"main"}
Timezone必须选 UTC（北京时间=UTC+8，下面 cron 用 UTC 写）
Schedule选 Advanced (cron)，填入 */30 1-7 * * 1-5
含义：UTC 1:00–7:30 每 30 分 = 北京 9:00–15:30 周一至五
Headers（点开 Add header 添加两行）
Header 1Accept  →  application/vnd.github+json
Header 2Authorization  →  Bearer <你的token>
⚠️ Token 安全建议（重要）：当前会话里用的那个全权限 PAT 已经多次暴露，建议到 GitHub 新建一个细粒度 token（Fine-grained）：只授权 leonmai/pushme 这一个仓库的 Actions: Read and Write，然后把上面 Header 2 里的 <你的token> 换成它，再去 Settings → Developer settings 把旧的 ghp_kk4...RUIO 撤销轮换。cron-job.org 上只放这个最小权限 token。
创建后验证
  1. 保存后，在 cron-job.org 该任务点 Run now（立即执行一次）。
  2. 到 GitHub 仓库 → Actions 页面，应看到一条新的 workflow_dispatch 运行，且盘中时段会收到微信推送。
  3. 之后每交易日 9:00–15:30 每 30 分钟自动触发，无需手动。
备选：用自己的服务器/VPS（不要 cron-job.org 也行）
